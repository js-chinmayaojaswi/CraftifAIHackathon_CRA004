Architecture & Methodology

The 5 Mandatory PipeGen Stages

A complete execution lifecycle from plain natural language to a high-speed compiled TensorRT edge pipeline.

1 Natural Language Prompt & Requirement Specification

PipeGen translates human intent into a structured specification with hazard polygons and QoS requirements.

01_requirement.json

// Natural Language Prompt:

"Build an edge vision perception pipeline using PipeGen that monitors an industrial work area in real-time. Ingest a video stream or camera feed, detect workers with YOLOv8, classify PPE compliance, track worker trajectories across restricted hazard zones, trigger instant safety violations over MQTT, and log structured incident telemetry to JSON audit logs with sub-15ms TensorRT inference latency."

// System Parameters:

  • Target Hardware: NVIDIA GeForce RTX 4050 Laptop GPU (6GB VRAM)
  • Input Resolution: 1920x1080 @ 30 FPS via nvv4l2decoder
  • Hazard Zone: Polygon [[450, 200], [1150, 200], [1150, 650], [450, 650]] (Crane machinery area)
  • Notification Broker: MQTT broker.hivemq.com (Topic: craftifai/pipegen/workplace_safety/alerts)

3 Model Configuration & ONNX Export

Selection of deep learning models from the CraftifAI catalog and export to ONNX with static 640x640 shape.

models/yolov8n_safety.onnx
Model Graph Specifications:
• Architecture: YOLOv8 Nano (Anchor-Free Detection)
• Parameters: 3,151,904 (Fused FP16)
• Compute FLOPs: 8.7 GFLOPs
• Input Tensor: 1 x 3 x 640 x 640 (NCHW)
• Output Tensor: 1 x 84 x 8400 (Bounding BBoxes + Classes)
Export Parameters:
• Format: ONNX Opset 18
• Static Dimension: Enabled for optimal TensorRT CUDA kernel autotuning
• Quantization: FP16 Half Precision Precision ready
